# Chupnow

A modern food delivery marketplace connecting customers with independent kitchens.

## Features

- Browse and search dishes from multiple vendors
- Customizable orders with proteins and extras
- Real-time order tracking
- User authentication and profiles
- Vendor dashboard for menu management
- Admin console for platform management
- Progressive Web App (PWA) support

## Tech Stack

- React + TypeScript
- React Router
- Tailwind CSS
- Lucide Icons
- Vite

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Development

This is a frontend-only build using localStorage for data persistence. Authentication, payments, and GPS tracking use mock adapters for demonstration purposes.
